# Tickwell brand files

The mark: an order email (the envelope and its lines) whose last line becomes the tick,
breaking out through the corner. Checked, and on its way out of the inbox.

| File | Use |
|---|---|
| `tickwell-mark.svg` | The mark on light backgrounds (transparent) |
| `tickwell-mark-on-dark.svg` | The mark on dark backgrounds (transparent) |
| `tickwell-app-icon.svg` | Square icon: profile pictures, app icons |
| `png/` | The same as PNG, for LinkedIn, email signatures and slides |

The gap where the tick crosses the envelope is a mask, so the files work on any background.

Colours: ink `#18301F`, green `#2E6B3B`, sage lines `#A9B8AC`, ground `#FAFBF8`.
Wordmark: Space Grotesk Bold, tight tracking (about -0.03em).
Below 24 px, use `src/tickwell/web/favicon.svg`: thicker strokes, one line.
